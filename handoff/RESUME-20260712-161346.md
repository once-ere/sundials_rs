SUN_TABLE_WIDTH 28→29). Where so, the same C example is compiled from the
untouched `sundials-7.7.0` tree with `-O3 -ffp-contract=off -DNDEBUG`,
Rust output must match the local C build byte-for-byte, and that local
output is committed under `localref/<solver>/<serialdir>/<name>.out`.
The harness checks localref automatically when the shipped ref differs.

is EPHEMERAL — it will likely be gone on resume.** To rebuild if a new
LOCAL-C ref is ever needed:

